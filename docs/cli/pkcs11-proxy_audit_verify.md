## pkcs11-proxy audit verify

Verify records, Merkle roots, and checkpoint signatures

```
pkcs11-proxy audit verify <log> [flags]
```

### Options

```
  -h, --help         help for verify
      --key string   audit verification public key file (default <log>.key.pub)
```
